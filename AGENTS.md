# Agent Instructions

This repository contains `gdashlint`, a Go CLI for linting Grafana dashboards.

## Guidelines for AI coding agents

- Do not implement dashboard linting behavior unless explicitly requested.
- Keep changes small, idiomatic, and testable.
- Prefer the Go standard library unless a dependency is clearly justified.
- Run `make check` or the narrowest relevant Go command after code changes.
- Update documentation and GitHub metadata when workflows or contributor expectations change.
